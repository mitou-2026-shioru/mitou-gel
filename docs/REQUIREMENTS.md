# 要件定義v0.1との対応

要件と提供機能の対応。M5Stackとの連携、温度制御、ジャミングによる硬さ制御は実証済みです。実証・テストの結果は[実証・テスト結果](VALIDATION.md)に記載します。

| 要件 | 提供機能 |
|---|---|
| A: 温度・硬さ・触覚面 | アプリから独立した正規化2軸を送信し、M5Stackで温度・ジャミングによる硬さを制御 |
| B-1: WatchのHR・HRV・時刻 | WatchのライブHR、日時、最新HRV取得。iPhoneのHealthKit読み取りも実装。運動情報は計測セッション中という文脈を使用 |
| B-1: 時間窓・個人内変化 | 120秒履歴、30秒平均、60秒傾向、個人ベースライン差 |
| C-1: HealthKit / Workout | WatchのHKWorkoutSession + HKLiveWorkoutBuilder、iPhoneのHKSampleQuery |
| C-2: 状態推定 | 生体変化を触覚表現用の連続値で保持。HRVは時刻付き補助情報。音声分類・ラッセル座標と触覚指令は別経路 |
| C-3: 通信 | Wi-Fi HTTP API、命令確認、接続断・再接続、固定2秒周期・遅延スキップ、2軸履歴表示 |
| D-1: temperature / stiffness | DeviceCommandで0〜1を送信。API v1で実デバイスと通信し、模擬サーバーでも同じ通信形式を利用 |
| E-1: 抽象層 | SensorReading → InternalState → HapticState → DeviceCommandを分離 |
| 感情・触覚の対応 | 「柔＋温」「硬＋冷」等の探索条件を手動操作し、印象を記録 |
| F: ユーザースタディ | 6条件、ランダム順、匿名ID、定量評価、自由記述、CSVの評価記録機能 |
| MVP: Watch → iPhone | WatchConnectivityによる測定日時付きライブ心拍送信 |
| MVP: iPhone → M5 | Wi-Fi HTTPによる正規化2軸の送信と命令応答の照合。実M5Stackとの連携を実証済み |
| MVP: M5 → 温度 / ジャミング | 温度制御・ジャミングによる硬さ制御を実証済み |
| MVP: 生体変化 → 触覚 | 心拍変化から触覚候補を自動計算し、時間窓平均をM5Stackへ送信 |
| G-1: 会話 | Core ML WhisperKit日本語認識、8秒窓、文字の表現ルール、2秒窓の声の特徴、学習済み68特徴MLPの音声分類とラッセル座標の参考表示 |
| G-2〜4: 入力の拡張インタフェース | CoreのHapticStateを入力アダプタから指定可能。入力の解釈とデバイス制御を分離 |
| 追加: 触覚時間窓 | 自動入力の10 / 30 / 60秒候補平均、2秒周期送信、手動の直接指定、変更時停止 |
| 追加: 相棒UI | オリジナルのゲルの相棒、温度・硬さの可視化、iPhoneからWatchへの触覚プレビュー |
| 安全性 | アプリで明示的出力開始、停止、陳腐化・通信断・異常停止、命令TTL。デバイス側の保護条件はDevice APIに規定 |
| 再現性 | 正規化指令、受理した目標、実測値をCSV記録し、同一条件の比較に使用 |
| 応答性 | Watchの新規サンプルを受信時に計算し、固定2秒周期で候補を平均・送信。音声は8秒窓＋推論遅延。物理温度の到達時間はデバイス次第 |
| 可観測性 | センサ値・日時・内部状態・目標・実測温度・実測圧力・Device State・命令IDを表示またはCSV記録 |
| モジュール性 | Core / Shared / iOS / Watch、解釈・マッピング・通信・物理制御を分離 |

## 完成レベルに対応する機能

| レベル | 提供機能・実証結果 |
|---|---|
| Level 1: 物理デバイス | M5Stackによる温度・ジャミング制御を実証済み |
| Level 2: プログラマブル化 | iPhoneから温度・硬さを独立指定し、APIで送信 |
| Level 3: センシング統合 | Watch心拍取得、内部状態計算、触覚マッピング、時間窓平均、指令送信 |
| Level 4: 触覚表現の評価 | 6条件の提示順、定量評価、自由記述、CSV共有の評価記録機能 |
| Level 5: コミュニケーション入力 | 音声・テキストからの触覚候補生成、音声分類とラッセル座標の表示・記録 |

## 仕様上の選択

- 通信はWi-Fi HTTPを採用。
- Watchの計測セッションは開始・終了を利用者が操作し、心拍・エネルギーとワークアウトをHealthKitに保存。
- iPhoneを前面に置いたライブデモを対象にし、バックグラウンドでのデバイス制御は停止。
- 生体情報はM5へ送らず、正規化された触覚指令だけを送信。
- HRVは最新サンプルの日時を明示し、心拍のライブ経路とは別の補助情報として扱う。
- 温度と硬さの正規化値は意味表現。℃や圧力の値、安全レンジは校正済みM5側の仕様に委ねる。
