# 実機操作・評価チェックリスト

M5Stackとの連携、温度制御、ジャミングによる硬さ制御を実証済みの構成で、接続・操作・評価を行うための手順です。チェックボックスは実行ごとの確認に使用します。

## 持参・事前準備

- [ ] iPhone・WatchのOSとペアリングを確認
- [ ] Xcodeの両ターゲットに開発Teamを設定し、実機へインストール
- [ ] iPhoneとWatchでHealthKit権限を確認
- [ ] M5Stackの型番、GPIO、電源、ヒーター、ポンプ、弁、温度・圧力センサ構成を確認
- [ ] M5のDevice API v1、TTL監視、温度フィードバック、安全停止の動作を確認
- [ ] 人肌ゲルと外装、センサ位置、清掃・交換方法を確認
- [ ] M5とiPhone用の同一LANを用意し、M5のIPを記録

## 1. iPhone → M5

- [ ] M5起動時のヒーター・ポンプ出力OFFを確認
- [ ] アプリ「設定」でM5のURLに接続し、実測・Device Stateを確認
- [ ] 「手動」で出力開始し、温度と硬さの各0 / 0.5 / 1を個別に送信
- [ ] 受信命令ID、目標値、実測値を照合
- [ ] 温度と硬さを同時指定し、独立性または相互干渉を記録
- [ ] 「停止」で安全側へ戻ることを確認

## 2. 安全停止と再接続

- [ ] Wi-Fiを切断し、TTL切れで6秒以内に駆動停止することを確認
- [ ] iPhoneを背景に移し、出力停止を確認
- [ ] iPhoneのプロセスを終了し、M5側TTLで停止することを確認
- [ ] 温度センサ断線・異常値時の停止を確認
- [ ] 過熱・過大圧力・ポンプ駆動時間の保護を確認
- [ ] 停止より古いsequenceの有効化指令を拒否することを確認
- [ ] 再接続後に勝手に出力を再開しないことを確認

## 3. 物性の確認

- [ ] ゲル表面の温度を独立した測定器でも確認
- [ ] 加熱・冷却機構の対応レンジとcold / neutral / warmの提示条件を確認
- [ ] soft / hardの差が知覚可能か確認
- [ ] 同じ指令を繰り返し、温度・圧力・触感の再現性を記録
- [ ] 数十回の繰り返しで膜・配管・ゲル・機構が破損しないか確認
- [ ] 液漏れ、電装への接触、過熱箇所がないか確認

## 4. Watch → iPhone → M5 → Gel

- [ ] iPhone「Watch」モード、Watch「計測を開始」で新しい心拍を確認
- [ ] 生体値の時刻が新しく、模擬入力と区別されていることを確認
- [ ] 安静状態の30秒でベースラインを校正
- [ ] 個人内心拍変化 → arousal → 目標値 → 実測値の順に確認
- [ ] Watchの計測終了から30秒の入力期限と停止を確認
- [ ] HRVが欠損・古い場合にも心拍経路が動作し、測定日時を表示することを確認
- [ ] 信号CSVを共有し、測定時刻から指令・変化開始までの遅延を確認

## 5. 簡易ユーザースタディ

- [ ] 参加者の同意、匿名ID、記録範囲、触れる時間を決定
- [ ] 6条件の物理的な校正と安定待ち時間を決定
- [ ] 条件の名前や温度・硬さの数値で印象を誘導しない提示手順を決定
- [ ] 物性の違い、想起される印象、場面、自然さ、コミュニケーション上の価値をインタビュー
- [ ] H1・H2用に単一軸と組み合わせを比較
- [ ] H3用に数値・文字による提示と触覚提示の比較条件を追加して実施
- [ ] 体験CSVとインタビュー記録を保存し、マッピング・筐体・入力・最終デモを修正

提示順、物理レンジ、接触時間、温度順応、インタビュー手順を揃え、H1〜H3に対応する条件を比較します。
