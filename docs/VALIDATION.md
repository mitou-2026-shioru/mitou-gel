# 実証・テスト結果

## 環境と対象

- macOS 26.7.1 / Xcode 27.1 RC、Swift language mode 5。
- アプリの対象はiOS 17以降、watchOS 10以降。

## M5Stackの実証

- iPhoneとM5Stackの連携を実証済み。
- M5Stackによる温度制御を実証済み。
- ジャミングによる硬さ制御を実証済み。

M5Stackに関する実証結果は利用者の確認に基づく。自動テストの結果は以下に記載する。

## 自動検証

- Swift Packageの45テスト成功。心拍処理、校正、鮮度、順序、正規化、通信形式、日本語表現ルール、触覚時間窓、固定周期、声の特徴、マイクのdBFS・メーター表示、小さい有声音の文字起こし採用を確認。
- 学習済みモデルの68特徴をPython版の参照値と比較し、全特徴の一致を許容誤差内で確認。
- Mac上のCore MLで合成音声窓から6クラスを推論し、Python版の分類確率との一致を確認。無音ではラベルを返さない。
- 変換時の33入力でCore MLと元のMLPを比較。最大分類確率差は約4.63×10⁻⁷。
- 確率からラッセル座標への投影、エントロピー、時間減衰、食い違い、外れ値、欠損次元、不正値、観測バッファの上限と順序を確認。
- iOSと埋め込みwatchOSの実機向けSDKビルド成功。音声分類モデルとメタデータはiPhone側に含む。
- Xcodeプロジェクトとソースの構文検証成功。WhisperKitは1.1.0へ固定。
- 模擬M5Stackの5テストでTTL、古い指令拒否、不正値、新セッションの初期停止、HTTP通信・命令ID応答を確認。

## 端末内モデル

### 文字起こし

WhisperKit経由のWhisper Base / Tiny / large-v3 Turboを選択できる。MacではTinyによる合成日本語音声1例の認識と、ネットワークを禁止した別プロセスでのキャッシュ読み込み・認識を確認済み。

### 音声分類

`tiny-lm/public/circumplex-model.json`の標準化68特徴・64ユニットReLU・6クラスMLPをCore MLへ変換。出典revision・SHA-256・変換結果は`iOS/Models/VoiceCircumplex.json`に保存する。

分類確率とラッセル座標は参考表示・記録用。触覚指令は声の特徴・文字の表現ルールから別経路で生成する。認識座標と正規化された温度・硬さ指令を独立した表現として扱う。

アプリの音声分類モデルは68特徴MLP。出典情報と変換結果はモデルのメタデータに保存する。上流にLICENSEファイルはない。モデルを配布する際は上流の利用条件を確認する。
